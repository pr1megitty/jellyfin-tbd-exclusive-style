# TBD Exclusive Style (Jellyfin plugin)

TorrentBD-style 3D poster carousel for the Jellyfin home page. Uses Primary (poster) images.
Based on lachlandcp's Editor's Choice plugin (MIT).

Add this repository in Jellyfin (Dashboard > Plugins > Repositories > +):

    https://raw.githubusercontent.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>/main/manifest.json

Release a new version: GitHub > Actions > "Build & Release" > Run workflow.
